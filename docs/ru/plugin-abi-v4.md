# Контракт ABI v4

Гость получает не более одного вызова одновременно на инстанс. Указатели
`i32` — это байтовые смещения в линейной памяти Wasm. Для event-гостя
используйте [`wg_v4_plugin!`](../../plugins/examples/common/src/v4.rs), для
lifecycle-метаданных — `wg_v4_metadata!`.

## Экспорты и возможности

| Экспорт | Сигнатура | Назначение |
|---|---|---|
| `wg_abi` | `() -> i32` | `0x0400`; старший байт — major-версия ABI |
| `wg_caps` | `() -> i64` | Биты возможностей ниже |
| `wg_buf_ptr`, `wg_buf_len` | `() -> i32` | Расположение и ёмкость IN-окна для event-гостей |
| `wg_out_ptr`, `wg_out_len` | `() -> i32` | Отдельное OUT-окно для event-гостей с OUT-возможностями |
| `on_event` | `(i64, i32, i32, i32, i32) -> i64` | `conn_id, phase, flags, in_ptr, in_len` |
| `on_accept` | `(i64, i64, i32) -> i32` | `ip_hi, ip_lo, port`; ненулевой результат запрещает |
| `on_close` | `(i64, i64, i64, i64) -> ()` | `ip_hi, ip_lo, rx_bytes, tx_bytes` |
| `on_close_ex` | `(i64, i64, i64, i64, i64) -> ()` | `conn_id, ip_hi, ip_lo, rx_bytes, tx_bytes`; предпочтителен вместо `on_close` |

Слова IP хранятся в big-endian, IPv4 кодируется как `::ffff:a.b.c.d`. События
используют младшие 32 бита возвращаемого значения: `0` разрешает, `1`
запрещает, `2 + index` выбирает маршрут до dial в `once` или заголовках
запроса. Отрицательные и выходящие за диапазон значения недопустимы. Вердикты
маршрутизации и запрета никогда не применяют OUT-эффекты.

| Бит | Возможность | Использование |
|---|---|---|
| 0 | `CapBlob` | Все события |
| 1 | `CapHeaderIndex` | HTTP-фазы заголовков |
| 2 | `CapStartLine` | HTTP-фазы заголовков |
| 3 | `CapConnInfo` | Необязательные метаданные соединения; текущий прокси их не передаёт |
| 4 | `CapStateIn` | Принимать state в IN |
| 5 | `CapStateOut` | Передавать следующий state в OUT |
| 6 | `CapOpaque` | Opaque-фаза потока |
| 7 | `CapMutation` | Передавать замену в OUT; listener также должен разрешить её в конфигурации |
| 8 | `CapLifecycle` | Lifecycle-план хотя бы с одним lifecycle-хуком |

Фазы тела не требуют state или mutation. При стандартном движке резервируйте не
менее 44 КиБ по `wg_buf_ptr` (первые 40 КиБ используются для IN); гостю с OUT
также нужно 4 КиБ по `wg_out_ptr`, не пересекающиеся с активной IN-областью.
Движок очищает OUT перед вызовом. Все нулевые байты или корректный OUT с нулём
секций означают отсутствие эффектов. Корректная секция может присутствовать
явно с нулевой длиной. Прокси хранит state только для гостей, объявивших оба
state-бита. Опущенный state оставляет его без изменений; пустой очищает байты,
но остаётся присутствующим в следующем IN. Замены прокси используют блоки до
2 КиБ; слот state тогда допускает 1 984 байта, чтобы оба эффекта помещались в
один OUT.

## Фазы и флаги

| Фаза | ID |
|---|---|
| Заголовки запроса | 1 |
| Тело запроса | 2 |
| Заголовки ответа | 3 |
| Тело ответа | 4 |
| Opaque-поток | 5 |

Флаги: `First = 1`, `Last = 2`, `Truncated = 4`, `ClientToServer = 8`,
`ServerToClient = 16`. Полный заголовочный блок несёт `First | Last`. Событие
тела несёт `First` на первом блоке и `Last` на последнем. Для тела нулевой
длины событие не передаётся. Короткое транспортное чтение может передать
терминальное событие `Last | Truncated` с пустым blob и `First`, если до него
не было события тела. Truncated-события никогда не фиксируют эффекты и не
пересылают свои байты. Флаги направления относятся к opaque-событиям; оба бита
одновременно недопустимы.

## Разметка envelope

Все целые числа little-endian, смещения отсчитываются от базы envelope, а не от
blob. 24-байтовый заголовок: `magic:u32, version:u16=1, header_len:u16=24,
total_len:u32, section_count:u16, stride:u16=16, arena_off:u32, arena_len:u32`.
Magic — числовой `0x57473445` для IN и `0x5747344f` для OUT. `total_len` и
`arena_off` выровнены на 8 байт. После заголовка идёт таблица; допускается не
более 8 секций. Каждая запись: `type:u16, reserved:u16=0, offset:u32,
length:u32, count:u32`. Типы строго возрастают. Смещения секций выровнены на
4 байта и лежат после таблицы; непустые секции не пересекаются. Индекс
заголовков ограничен 512 записями на уровне движка.

| ID | Секция | Расположение |
|---|---|---|
| 1 | Blob (обязательна в IN) | Начинается с `arena_off` |
| 2 | Индекс заголовков | Вне arena, после неё |
| 3 | Start line | Вне arena, после неё |
| 4 | Информация о соединении | Вне arena, после неё |
| 5 | State | В arena, после blob в IN; необязательна в OUT |
| 6 | Замена | Только arena OUT |

`count` равен нулю у известных секций, кроме индекса заголовков. Каждая запись
индекса: `name_off:u32, value_off:u32, name_len:u16, value_len:u16, aux:u32`;
host передаёт `aux=0`. Имя и значение лежат внутри blob, одинаковые имена
остаются отдельными записями. Start line — 24 байта: три `u32`-смещения, затем
три `u16`-длины, форма target (`u8`), флаги (`u8`) и четыре зарезервированных
байта. Поля запроса — method, target, version; поля ответа на тех же позициях —
reason phrase, трёхзначный status, version.

Информация о соединении — необязательная
[80-байтовая структура](../../internal/plugin/abi4/envelope/envelope.go), чьи
смещения SNI и ALPN, если они непусты, указывают внутрь blob. Неизвестные
IN-секции можно пропускать после структурной проверки. Неизвестные OUT-секции
отклоняются. OUT копируется в память host до переиспользования инстанса.
